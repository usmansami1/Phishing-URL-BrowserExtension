## 🎯 About The Project

> **Phishing URL Browser Extension** is a security-focused browser extension that analyzes URLs in real-time to detect and warn users about potential phishing attacks. Stay safe while browsing — let AI guard your clicks.

<div align="center">

```
 ╔══════════════════════════════════════════════════════════════╗
 ║                                                              ║
 ║   🌐  Browse   →   🔍  Analyze   →   🛡️  Protect           ║
 ║                                                              ║
 ║   Real-time URL scanning with machine learning models        ║
 ║   to keep you safe from phishing & malicious websites        ║
 ║                                                              ║
 ╚══════════════════════════════════════════════════════════════╝
```

## 🚀 Getting Started

### Prerequisites

- **Git** installed on your machine
- A **GitHub** account with repo access
- **Google Chrome** or any Chromium-based browser

### 📥 Clone the Repository

```bash
git clone https://github.com/usmansami1/Phishing-URL-BrowserExtension.git
```

### 🌿 Create Your Own Branch

> [!IMPORTANT]
> Every team member **must** create their own branch before making any changes.

```bash
git switch -c yourName
```

<sup>💡 This will create your own branch locally on your laptop.</sup>

<img src="https://user-images.githubusercontent.com/73097560/115834477-dbab4500-a447-11eb-908a-139a6edaec5c.gif" width="100%">

## 🔄 Daily Workflow

> [!WARNING]
> **Always** run these commands before starting to code to stay in sync!

<details>
<summary>🔃 <b>Step 1 — Update your local main</b> (click to expand)</summary>
<br/>

```bash
# Switch to main branch
git switch main

# Pull the latest changes
git pull origin main
```

> This ensures your local `main` is up to date with the remote repository.

</details>

<details>
<summary>🔀 <b>Step 2 — Sync your branch with main</b> (click to expand)</summary>
<br/>

```bash
# Switch back to your branch
git switch yourName

# Merge latest main into your branch
git merge main
```

> ✅ Now you're on your branch and fully up to date!

</details>

<details>
<summary>📤 <b>Step 3 — Push your changes</b> (click to expand)</summary>
<br/>

```bash
# Stage all changes
git add -A

# Commit with a descriptive message
git commit -a -m "Added my data in readme"

# Push to your remote branch
git push -u origin yourName
```

> After pushing, go to **GitHub** and create a **Pull Request** with details of what changes you've made.

</details>
